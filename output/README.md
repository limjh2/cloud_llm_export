# Output

Owner-facing reports and analyses may be stored here in a filled local instance.
They are non-canonical and collection-derived output must never enter the public
template.

Deliverables include both written answers and reusable artifacts — "from this
project but not of this project". Name one dated entry each:
`YYYY-MM-DD-topic.md`, or a `YYYY-MM-DD-topic/` folder for a package. Session
handoffs also live here, named `YYYY-MM-DDTHHMMSS±HHMM-session-handoff.md`; see
`HANDOFF_PROTOCOL.md`.

This folder is untracked apart from this file and `.gitignore`, so it is a
transit lane rather than storage. Anything worth keeping is promoted to its own
tracked top-level home. Agents do not process, prune, or reorganize it — its
contents belong to the owner.
